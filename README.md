# GPU Priority Context Menu
A couple reg files that add context menu entries to change a program's GPU priority in the Windows 10/11 Graphics Settings without the need to go do it manually. Just right-click a game/program and away you go.

## Usage
Install the .reg files by opening them, and confirm when asked if you want to make changes to the registry.

Once installed, right-click on any .exe file and you will now have the option to set it to "High Performance" in Graphics settings, or simply reset it back to the Windows default (which is actually just not having an entry in the graphics settings menu at all lol)

## Purpose
This was mostly done as a learning experiment, and also because I'm lazy and it's tedious and inconvenient to add games one-by-one via the Settings UI or via regedit. This is easier and more intuitive, and I got to use fancy shell icons and stuff. :3
